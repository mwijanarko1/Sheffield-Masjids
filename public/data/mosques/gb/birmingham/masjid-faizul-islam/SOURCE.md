# Data source

Prayer times for **Masjid Faizul Islam** (`birmingham/masjid-faizul-islam`) come from the mosque’s **Facebook** posts (monthly timetable images/PDFs), not from a website API.

- Website `faizulislam.co.uk` does not resolve / is not a usable source.
- Ask the user for the Facebook timetable (or paste/OCR) when adding a new month.
